# 📚 Estudos .NET MAUI

Este repositório tem como objetivo **centralizar e organizar meus estudos sobre .NET MAUI**, servindo como uma base de conhecimento para aprendizado, revisão e consulta durante o desenvolvimento de aplicações.

O conteúdo é organizado a partir das aulas e práticas realizadas durante o curso, com anotações, exemplos, conceitos importantes e projetos desenvolvidos ao longo da jornada.

## 🎯 Objetivos

* Consolidar os conhecimentos adquiridos durante o estudo de .NET MAUI.
* Registrar conceitos e exemplos práticos para facilitar futuras revisões.
* Organizar o conteúdo de forma progressiva, acompanhando a evolução dos estudos.
* Documentar projetos e exercícios desenvolvidos durante o aprendizado.
* Criar uma base de consulta para utilização em projetos futuros.
* Manter o conhecimento sincronizado e versionado por meio do GitHub.

## 🗂️ Organização

As notas estão organizadas de acordo com as seções e aulas estudadas. O índice principal serve como ponto de entrada para navegar pelo conteúdo.

A estrutura poderá evoluir conforme novos conceitos, projetos e materiais forem adicionados ao repositório.

## 🛠️ Ferramentas utilizadas

* **.NET MAUI** — desenvolvimento de aplicações multiplataforma.
* **C#** — linguagem utilizada no desenvolvimento.
* **Visual Studio** — ambiente de desenvolvimento.
* **Git e GitHub** — versionamento e armazenamento do material.
* **Obsidian** — organização e consulta das anotações.

## 📖 Como utilizar

O repositório deve ser utilizado como uma **base de estudos contínua**.

A recomendação é seguir a trilha apresentada no índice, acompanhando as seções na ordem sugerida. As notas também podem ser acessadas individualmente para revisar um conceito específico.

> 💡 **Ideia principal:** este repositório não serve apenas para registrar o que foi estudado, mas para construir uma base de conhecimento que possa ser consultada e reutilizada em projetos futuros.

## 🚀 Evolução

Este repositório será atualizado conforme o avanço dos estudos em .NET MAUI, incorporando novos conteúdos, exercícios, projetos e aprendizados práticos.
